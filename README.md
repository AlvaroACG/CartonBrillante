## Configuración para compilar
Requiere Android Studio y un SDK compatible con build.gradle. Crea tu propio proyecto de Firebase, registra el applicationId y coloca tu google-services.json en app/. Ese archivo no está incluido. Configura claves de mapas u otros servicios en un archivo local y no las publiques.
